This project is part of the *RSNA Knee Abnormality Detection* Kaggle competition.

The goal of this competition is to develop machine learning models that can detect clinically important abnormalities in knee MRI scans.

This project explores:

* Medical image preprocessing
* Exploratory data analysis
* Data preparation and augmentation
* Deep learning for image classification
* Model training and evaluation
* Kaggle submission
